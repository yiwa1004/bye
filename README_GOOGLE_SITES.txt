YIWA PORTFOLIO — GOOGLE SITES USE

FILES
1) yiwa_google_sites_embed.html — self-contained preview / embed source
2) google_sites_embed_code.txt — same source as plain text for copy/paste
3) index.html + assets/ — lighter hosted version

GOOGLE SITES
A. Try direct embed first:
   Google Sites > Insert > Embed > Embed code > paste the complete content from google_sites_embed_code.txt.
   Stretch the embed block to full width and give it a tall height.

B. If Google Sites rejects the code because of size/security restrictions:
   Upload the lighter index.html + assets folder to any static host, then in Google Sites choose Insert > Embed > By URL.
   This gives the same design and animation.

BEFORE PUBLISHING
- Replace YOUR_EMAIL in the Contact section.
- Replace the Instagram / Link href.
- Replace the CV href with your PDF URL.

HERO INTERACTION
- Objects slowly float and rotate.
- Mouse movement adds subtle parallax.
- Click produces a gentle breathing pulse.
- After ~2.6 sec objects settle around YIWA.
